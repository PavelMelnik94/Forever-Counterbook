# Product Brief

## Product

Forever Counterbook is a free, open-source, patch-aware PvP knowledge base and personal learning journal for WoW: Forever. Its primary value is deliberate learning before and after combat; a compact live helper is secondary and must never automate play or claim hidden state.

## Audience and profiles

The committed profiles are Restoration Shaman, Enhancement Shaman as a levelling profile, SL/SL Warlock, Arms Warrior as a PvP damage profile, Restoration Druid, and Restoration/Balance Druid.

## Core loop

1. Select a Player Profile and Matchup Card.
2. Review Threats, Responses, the Attack Window, Critical Error, and personal reminders.
3. Fight without addon automation.
4. Record a Journal Entry manually and notice repeated Mistake Tags over time.
5. Revisit changed or stale knowledge when the Patch Dataset is updated.

## Differentiation

- Evidence Status and Sources make uncertainty visible.
- Patch Dataset and core code evolve independently.
- Matchup Journal turns static advice into a personal learning loop.
- RU and EN are first-class.
- No telemetry, premium profiles, external ratings, or in-game donation solicitation.

## Success

MVP succeeds when a player can find a relevant card, understand what is known versus assumed, save a private note, recover it after reload, and see whether the knowledge matches the current Patch Dataset.
