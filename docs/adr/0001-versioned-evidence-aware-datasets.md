# Use versioned, evidence-aware datasets behind one catalog interface

Forever Counterbook will load patch-specific matchup knowledge through a single catalog interface and require every countermeasure to declare whether it is Confirmed, a User Note, or an Assumption. Confirmed items must reference a recorded Source. This deliberately rejects a simpler unlabelled table because client limitations and balance changes make stale or inferred advice easy to mistake for live facts; the separation also lets later patches and community-authored data change without rewriting the viewer.
