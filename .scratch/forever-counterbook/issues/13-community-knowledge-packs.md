# 13: Verified community Knowledge Packs

**What to build:** Let players install separately distributed Knowledge Packs whose schema, patch compatibility, Sources, and trust status are validated before use.

**Blocked by:** 11: Version 1.0 class and race coverage.

**Status:** ready-for-agent

- [ ] Pack compatibility is explicit and failures do not corrupt bundled data.
- [ ] Confirmed items require accepted Sources under the same evidence policy.
- [ ] Pack origin and trust status are visible to the player.
- [ ] Packs cannot add executable combat automation.
